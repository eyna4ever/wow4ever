    In brief

    127 WoW Forever mounts, each with its game icon: official French and English name, faction, level, price recorded in the game files and effect. Acquisition is given for 32 of them (Legacy, shop pack, class spell, exchange quest, vendor to be confirmed); for the others, the game files do not give it.[4][1][2][6]

    Key points

    • 127 mounts, all illustrated with the game icon.[4] Game data (client 1.60.1.70862)
    • 2 official acquisitions: Reins of the Spectral Bear (Legacy) and Cerulean Prideclaw (Skyborne pack).[1][2]
    • 21 swift mounts offered by exchange quests, and 5 class mounts (spells): quests and NPCs to be confirmed.[5] Unconfirmed — to be confirmed
    • Mounts without known acquisition are sorted by faction and required level, with the price recorded in the game files.[4] Game data (client 1.60.1.70862)
    • 4 Horde mounts (wolf horns) sold by Ogunaro Wolfrunner in Orgrimmar, according to an unofficial database: to be confirmed.[6] Unconfirmed — to be confirmed

    How to read this list

    French and English names, quality, faction, required level, price and effect come from the game files (client 1.60.1.70862). “Official” acquisition comes from the cited Blizzard articles. Quests, NPCs and zones come from game quest data completed by players: they remain to be confirmed. When the game files do not say how to get an entry, the card says so (“not given”): nothing is added from memory or from another version of the game. A price recorded in the game files does not prove that a vendor sells it in Forever, and the presence of an entry in those files does not prove it can be obtained in Forever.[4][5] Unconfirmed — to be confirmed

    Each card shows the item’s official icon, read from the WoW Forever game files (client 1.60.1.70862) and only converted to WebP, unretouched (game images © Blizzard Entertainment). When no game image exists for an entry, no image is shown.[4] Game data (client 1.60.1.70862)
