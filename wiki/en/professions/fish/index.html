    In brief

    Blizzard has not published an official fish-by-zone list for World of Warcraft: Forever. This page gathers 37 fish and related catches recorded in game data (cooking and alchemy guides, client build 1.60.1.70862 as of 7 November 2026, and the Forever item catalog). Names and required skills come from the game files. An acquisition marked “unknown” remains to be confirmed. Zone and required fishing skill are not given in that data: they are not filled from Classic tables. Cooking recipes already documented are linked to /en/professions/cooking-recipes/. Fishing profession recipes stay on /en/professions/fishing-recipes/.[1][2][3][4][5][6]

    Key points

    • 37 rows from the game files (client 1.60.1.70862); 0 with a fishing zone in that data; 0 with a required fishing skill (zone and skill remain to be confirmed).[3][4][5][6] Game data (client 1.60.1.70862)
    • French names come from the localization of the catalog and profession guides consulted. Whimsyfin (Fantaileron) and Seasonal Fish Steaks have high item ids, filed under new items in Forever.[3][4][5][6] Game data (client 1.60.1.70862)
    • A Forever fishing guide, consulted the same day, contains a “Zones (Classic)” table and warns that locations may differ in Forever: that table is not used.[3][4][5][6] Game data (client 1.60.1.70862)

    How to read this list

    Fishing profession recipes (bowl, rack, hut) stay on the already published sheet /en/professions/fishing-recipes/. This page adds the fish and related catches, not a second fishing-recipe list.[1][2][3][4][5][6]

    • Every row comes from the game files (client 1.60.1.70862) or the Forever item catalog. Fishing zone and required skill, not given, remain to be confirmed.[3][4][5][6] Game data (client 1.60.1.70862)
    • Required fishing skill and zone (or water type) are not on the item pages or in the 1.60.1.70862 profession guides consulted: those cells stay as “not given”.[3][4][5][6] Game data (client 1.60.1.70862)
    • The price shown is the item’s sell price, when it appeared on the Forever item page. No purchase vendor was named for these fish.[3][4][5][6] Game data (client 1.60.1.70862)
    • Recipe links point to the cooking or alchemy sheets already online, without drop rates.[3][4][5][6] Game data (client 1.60.1.70862)

    Scope and Forever evidence

    The cooking and alchemy guides consulted are stamped: game data, WoW Forever client build 1.60.1.70862, as of 7 November 2026. The item database in the same documentation uses the same build. Item pages are labelled as items in WoW Forever, but they do not give a source location (“not known yet”).[3][4][5][6] Game data (client 1.60.1.70862)

    No Forever-specific catch-by-zone table (including Zephras Isle and Shen’dralas) was found in these sources. “Related pages” links on some item pages (for example Shen’dralas) are a generic footer, not a fishing location: they are not used as zones.[3][4][5][6] Game data (client 1.60.1.70862)

    What is confirmed / what remains to be confirmed

    Confirmed by official sources

    • Blizzard announced over 600 new recipes, without publishing a complete list, and has not, in the official articles cited, published a fish-by-zone list.[1][2]

    Still to be confirmed

    • Zone or water type, and required fishing skill: not given in the Forever data consulted (item pages: source “not known yet”).
    • No catch table for Zephras Isle, Shen’dralas or another Forever-only zone was found.
    • Purchase vendor and in-game buy price: not given for these fish (only the item sell price was, when present).
    • Quest or event fish that may exist in Forever were not added if they did not appear in the 1.60.1.70862 profession guides or the trade-goods catalog consulted.
